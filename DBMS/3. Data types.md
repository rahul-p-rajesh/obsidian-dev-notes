```
1 byte is 8 bits

Unsigned Max = 2^(bytes × 8) - 1 
Signed Max = 2^(bytes × 8 - 1) - 1 
Signed Min = -2^(bytes × 8 - 1)

e.g
```

| Bytes | Bits | Signed Max | Signed Min | Actual Value                                                                                            |
| ----- | ---- | ---------- | ---------- | ------------------------------------------------------------------------------------------------------- |
| 1     | 8    | 2⁷ - 1     | -2⁷        | 2⁷ = 128 → max **127**, min **-128**                                                                    |
| 2     | 16   | 2¹⁵ - 1    | -2¹⁵       | 2¹⁵ = 32,768 → max **32,767**, min **-32,768**                                                          |
| 3     | 24   | 2²³ - 1    | -2²³       | 2²³ = 8,388,608 → max **8,388,607**, min **-8,388,608**                                                 |
| 4     | 32   | 2³¹ - 1    | -2³¹       | 2³¹ = 2,147,483,648 → max **2,147,483,647**, min **-2,147,483,648**                                     |
| 8     | 64   | 2⁶³ - 1    | -2⁶³       | 2⁶³ = 9,223,372,036,854,775,808 → max **9,223,372,036,854,775,807**, min **-9,223,372,036,854,775,808** |

```
8 bits = 1 Byte 
1024 Bytes = 1 KB (Kilobyte) 
1024 KB = 1 MB (Megabyte) 
1024 MB = 1 GB (Gigabyte) 
1024 GB = 1 TB (Terabyte)
```

## 1. **Numeric**
```mysql

TINYINT      -- 1 byte,  -128 to 127  (or 0–255 unsigned)
SMALLINT     -- 2 bytes
MEDIUMINT    -- 3 bytes
INT / INTEGER-- 4 bytes
BIGINT       -- 8 bytes

DECIMAL(p,s) -- exact, e.g. DECIMAL(10,2) for money
NUMERIC(p,s) -- alias of DECIMAL
FLOAT        -- 4-byte approx
DOUBLE       -- 8-byte approx
BIT(n)       -- bit field

BOOLEAN      -- alias for TINYINT(1); 0 = false, 1 = true


```

## 2. Strings 

```sql

CHAR(n)      -- fixed-length, padded
VARCHAR(n)   -- variable-length, up to 65,535
TINYTEXT     -- up to 255
TEXT         -- up to 64 KB
MEDIUMTEXT   -- up to 16 MB
LONGTEXT     -- up to 4 GB

BINARY(n) / VARBINARY(n) -- binary string,when you're storing data that is **not  human-readable text** and where **exact byte matching** matters. for e.g session token
--binary hash the value while storing so it is encrypted


TINYBLOB / BLOB / MEDIUMBLOB / LONGBLOB  -- binary large object

ENUM('a','b','c')   -- one of a fixed list
SET('a','b','c')    -- zero or more from a fixed list
```
